## If you get stuck

1. **Re-read the guide for that clip** — the exact command is almost always there.
2. **Ask the agent.** Paste the error into the Antigravity chat and say what you were trying to do. That is the whole point of the course.
3. **Check the app is running** — most "nothing happens" issues are the app not being served, or MCP not connected.
